# typhoon_ocr

Pure-Dart foundation for Typhoon OCR.

This package owns the platform-neutral document models, parser, built-in document definitions, validation primitives, and document-specific validators used by `typhoon_ocr_flutter`.

It has no Flutter SDK dependency, so the same structured OCR layer can be reused by Dart CLI, server, worker, and test environments.

> This package is staged inside the monorepo first. Hosted publication and the `typhoon_ocr_flutter` 1.1.0 release are handled in the following release PR.
